You are one pass of a loop. You start with no memory; the code, the git history and these files are the memory.
features.json lists the features. After every pass the loop runs the tests and records which ones pass.

Work on one feature only: the first one that fails.
1. Read cart.py.
2. Change only the lines that feature needs, with Edit.
3. Run that feature's check, for example `python3 test_cart.py rounding`, and stop when it says PASS.
